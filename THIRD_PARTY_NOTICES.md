# Avisos de terceros

Este plugin incluye, sin cambios, skills de otros autores para que se instalen con él. Cada carpeta conserva su licencia (`LICENSE`) y un `ORIGEN.md` con el repositorio y el commit del que se copió. Todo lo demás del plugin es MIT (`LICENSE` en la raíz).

| Skill | Autor | Repositorio | Licencia |
|---|---|---|---|
| `impeccable` | Paul Bakaus | https://github.com/pbakaus/impeccable | Apache-2.0, con su `NOTICE.md` |
| `web-design-guidelines` | Vercel | https://github.com/vercel-labs/agent-skills | MIT (según su README) |
| `vercel-react-best-practices` | Vercel | https://github.com/vercel-labs/agent-skills | MIT (según su README y la skill) |
| `emil-design-eng` | Emil Kowalski | https://github.com/emilkowalski/skills | MIT |
| `mobile-native` | Emil Kowalski | https://github.com/emilkowalski/skills | MIT |
| `break-ui` | Emil Kowalski | https://github.com/emilkowalski/skills | MIT |
| `fixing-accessibility` | Julien Thibeaut | https://github.com/ibelick/ui-skills | MIT |

`impeccable` incluye a su vez material derivado de `ehmo/platform-design-skills` (MIT), según su `NOTICE.md`.

Los plugins de los que depende este (`feature-dev`, `pr-review-toolkit`, `frontend-design`, `claude-security`) no se copian: Claude Code los instala desde el marketplace oficial de Anthropic con sus propias licencias.
